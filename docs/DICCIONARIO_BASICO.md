# Diccionario básico de indicadores

| Indicador | Definición | Unidad / cautela |
|---|---|---|
| Producción de aceite | Aceite producido según unidad territorial y campaña | t; no confundir con aceituna agrícola |
| Precio de referencia | Media simple provincial de precios publicados disponibles | €/kg; no necesariamente precio efectivo de venta |
| Variación interanual | Cambio frente a campaña anterior | % |
| Precipitación | Suma de lluvia en la ventana de una provincia y campaña | mm; no sumar provincias para representar región |
| Días TX35 media estación | Media de días de Tmax sobre umbral por estación | días/estación; validar inclusión del umbral |
| Porcentaje TX40 | Observaciones TX40 / observaciones Tmax válidas | %; fuente 0–100, medida puede dividir por 100 para formato porcentaje |
| Coste técnico estimado | Modelo de coste para campaña, tipología y escenario | €/kg de aceite; no gasto observado de explotación |
| Margen estimado | Precio referencia − coste estimado | €/kg; resultado de escenario |
| Importaciones | Peso neto comercial de aceite importado desde Túnez por España | t = kg/1000; TARIC 1509 |
| Valor importado | Valor de la importación desde Túnez | M€ = euros/1.000.000 |
| Valor unitario importado | Valor total / peso total | €/kg; no es coste de producción tunecino |
| Lluvia anual antecedente | Precipitación asociada a una cosecha objetivo en ventana antecedente | mm; variable `AN_Pmm` del dataset analítico |
| Producción analítica | Producción por provincia–cosecha vinculada al clima | t; variable `ProduccionAceiteT` |
